# 20대 건강 변화 분석 보고서

확인일: 2026-10-03. 모든 수치는 공개 통계이며 이 분석이 원시자료를 재분석한 것은 아니다.

## 질문

"요새 20대 건강이 나빠졌다"는 통념이 공개 통계로 확인되는가. 확인된다면 **어떤 지표가, 어느 연령 구간에서, 어느 기간에** 달라졌는가.

## 4칸 명세

| 칸 | 내용 |
| --- | --- |
| 목표 | 20대 건강 관련 공개 지표의 변화 방향과 크기를 확인하고, 결론 등급을 붙인다 |
| 제약 | 원시자료 접근 없음. 공개 보고서·논문·보도자료의 공표값만 사용. 연령 구간이 다른 값을 잇지 않는다 |
| 검증 조건 | 성별 값으로 전체값을 역산해 표 내부 정합성을 확인하고, 파생값(%p·배수)을 손계산한다 |
| 비목표 | 원인 규명, 정책 평가, 개인 수준 예측, 국제 순위 비교 |

연령 구간은 자료마다 19~29 · 20~29 · 18~29 · 19~34로 다르다. 이 분석은 **구간을 섞지 않았고**, 모든 수치에 구간을 함께 적었다. 19~34세 자료(청년 삶 실태조사 등)는 20대 지표로 쓰지 않았다.

## 방법

1. GPT-6.1 Sol 하위 에이전트 4대가 각각 신체·대사 / 정신건강 / 건강행동 / 반증·맥락을 조사하고 `research/*.md`에 출처·연령·기준연도·n·확인경로(직접/2차인용)를 기록했다.
2. 주 에이전트가 핵심 수치를 1차 출처에서 다시 확인했다. 자살률은 뉴스 2차인용으로 올라온 값을 통계청 보도자료 PDF를 내려받아 `pdftotext -layout`으로 원표에서 다시 전사했다.
3. 성별 값으로 전체값을 역산하는 항등식으로 표 내부 정합성을 검산했다(`verification.md`).
4. 검산을 통과한 값만 `chart-data.json`에 넣고, 덱의 모든 차트는 그 파일에서만 그린다.

## 결과

### 악화가 확인된 것

- **비만** 20~29세 남성 32.2%(2013) → 45.0%(2022), 여성 10.3% → 18.7%. 원문은 여성 20대가 전 여성 연령군 중 증가 폭이 가장 컸다고 적었다.
- **제2형 당뇨병** 19~29세 0.73%(2010) → 1.54%(2020), 2.11배.
- **대사증후군** 19~29세 5.8%(2007-09) → 8.7%(2019-21).
- **자살률** 20~29세 18.0명(2013) → 22.2명(2023), 인구 10만 명당. 20대 사망원인 1위는 자살이며 2013년에도 1위였다.

### 수준과 속도를 구분해야 하는 것

2022년 20대 비만율 31.3%는 **전 연령대 중 가장 낮다**(30대 41.8%, 40대 41.9%). "가장 아픈 세대"가 아니라 "가장 빨리 변하는 세대"다.

### 개선이 확인된 것

- **근력운동 실천율** 19~29세 28.6%(2014) → 35.7%(2022).
- **궐련 현재흡연율** 19~29세 24.8%(2019) → 18.7%(2022).
- **유산소 신체활동 실천율** 57.8%(2020) → 69.2%(2022), 코로나 이전 2018년 63.8%보다 높다.

### 주장할 수 없는 것

- **"20대 우울증 유병률 2배"** — 늘어난 것은 진료 인원(2021년 177,166명, 2017년 대비 +127.1%)이다. 같은 연령·같은 기간의 PHQ-9 유병률 시계열을 확인하지 못했다.
- **"전반적 악화"** — 운동·흡연은 같은 기간에 좋아졌다.
- **원인** — 모두 반복 횡단조사와 행정통계다. 같은 사람을 추적하지 않았다.

## 대안 설명 검증

진료 인원 증가에 대한 두 대안 설명을 직접 넣고 돌려 봤다.

| 대안 설명 | 결과 |
| --- | --- |
| ① 20대 인구가 줄어서 비율이 커 보인다 | **기각.** 인구는 2018년 682.4만 → 2024년 595.6만으로 12.7% 줄었지만, 진료 인원을 비교한 2017~2021년에는 2.3%밖에 줄지 않았다. 127% 증가를 분모로 설명할 수 없다 |
| ② 발견 기회가 늘었다 | **남음.** 2019년에 우울증 검사가 20세·30세로 확대되고 국가검진 대상에 20~30대가 추가됐다. 비교 구간 안에 있다. 다만 기여율은 측정되지 않아 "제도 변화 때문이다"가 아니라 "둘을 분리할 수 없다"까지만 말할 수 있다 |

## 검증

`verification.md`에 전체 기록이 있다. 요점:

- 통계청 표 12에서 (전체−여)÷(남−여)로 역산한 남성 인구비중이 2013·2022·2023년 모두 0.52~0.53으로 일치해 표 내부 정합성과 전사 정확성을 확인했다.
- 같은 검산을 비만에 적용하면 2013년 0.525, 2022년 0.479로 어긋난다. 검진 수검자 구성이 달라졌거나 2013년 전체값(그림 판독)이 부정확하다. **조치**: 비만의 연도 비교는 성별 값으로만 제시했다.
- 표의 성비 행 1.4를 20.9÷14.8 = 1.41로 재현했다.

## 한계

- 원시자료 재분석이 아니라 공표값 전사다. 신뢰구간·추세검정은 대부분 확보하지 못해, 단순 차이를 통계적으로 유의하다고 쓰지 않았다.
- 스트레스·근력운동·흡연·인구 값은 재게시본에서 읽은 **2차인용**이다. 자살률·비만·당뇨·대사증후군은 1차 자료에서 직접 전사했다.
- 조사도구 변경으로 시계열이 끊긴 지점이 있다(2014 신체활동 IPAQ→GPAQ, 2014 근력운동 조사방식, 2016 수면 문항 분리, 2019 흡연 문항, 2022 영양 회상기간). 끊긴 구간을 한 추세로 잇지 않았다.
- 2020~2022년을 가로지르는 비교에는 코로나 영향이 섞여 있다.
- 20대 전자담배 제품별 사용률, 수면부족 비율, 주관적 건강인지율의 장기 시계열은 확보하지 못했다.
