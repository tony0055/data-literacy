# 컴포넌트와 문구

실제 값의 기준은 `../src/deck.css`다. 확인 화면은 `../design-standard.html`.

## 장 종류

| 클래스 | 쓰임 |
| --- | --- |
| `.slide` | 기본 내용 장 (흰 바탕) |
| `.slide.bg-paper` | 중립 바탕 변주 |
| `.slide.bg-evid` | 질문·전환 장 |
| `.slide.bg-ink.cover` | 표지 |
| `.slide.bg-ink.part` | 파트 표지 |

어두운 장은 표지·파트 표지·마무리로 한정한다.

## 뼈대

```
.slide
  .head  →  .kicker ( b + span ) / .headline / .lead
  .body  →  .grid > .cN  또는  .stack
  .sowe  →  b + 한 문장
  .foot  →  .source + .pg
```

## 블록

| 컴포넌트 | 클래스 | 쓰임 |
| --- | --- | --- |
| 결과표 | `.chk` (+ `.big`; 열 `.area` `.item` `.val` `.lbl`, 행 `.gap` `.hi`) | 방향 계약의 기본 뼈대. 항목마다 한 줄에 결과 · 라벨 · 판정 |
| 판정 도장 | `.verdict` (`.ok` `.no` `.pass` `.fail` `.hold` `.limit`) | 2px 테두리, 글자색이 곧 판정 색 |
| 선 구분 묶음 | `.ruled` (항목에 `.worse` `.better` `.unsure`, 머리줄 `.head-row`, 인용 `.q`) | 카드 대신 위아래 1px 선으로 나눈 묶음 |
| 카드 | `.card` (+ `.flat` `.paper` `.evid` `.worse` `.better` `.unsure`) | 같은 그룹이라는 뜻이 있을 때만. 1px 선만, 그림자 없음. 현재 덱 본문에는 쓰지 않음 |
| 핵심 박스 | `.key` (`.k` 라벨 + `.v` 한 문장) | 장의 결론을 한 번 더 못박을 때 |
| 질문 블록 | `.ask` (`.q` + 설명) | 도입 질문. 한쪽 색 띠는 두지 않는다(AI 티) |
| 대조 2열 | `.vs` (`.no` / `.ok`) | 틀린 읽기 / 맞는 읽기 |
| 수식 | `.eq` (`.f` 식 + `.legend` 기호 뜻 + `.plug` 실제 값 대입) | 기호를 쓰면 같은 장에 뜻과 대입 예를 함께 |
| 번호 | `.idx` (+ `.ghost`) | 단계 |
| 칩 | `.chip` (+ 의미 변형) | 1~3개 명사 |
| 목록 | `.dots` (+ 의미 변형) | 점 목록 |
| 표 | `.tone` (`.n` 숫자 열, `.hi` 강조 행) | 지표 비교 |
| 큰 수치 | `.num` + `.unit` + `.delta.up/.down` | 핵심 값과 변화량 |

## 차트

| 부품 | 클래스 | 규칙 |
| --- | --- | --- |
| 묶음 | `.chart` | 제목 → 부제 → SVG → 주석 → 출처 순 |
| 제목 | `.chart-title` | 결론형 한 줄 |
| 부제 | `.chart-sub` | 축·분모·구간 폭 같은 읽는 조건 |
| 눈금 | `svg .tick` | 18px, `--chart-axis`(gray-700) |
| 직접 라벨 | `svg .vlab` | 18px 굵게, 값을 막대·점 옆에 |
| 축 이름 | `svg .alab` | 18px, 단위를 반드시 포함 |
| 격자 | `svg .grid line` | gray-200, 기준선만 `.base` |
| 막대 | `.b-evid` `.b-worse` `.b-better` `.b-neutral` | 강조 1색 + 중립 회색 |
| 선 | `.l-evid` `.l-worse` `.l-neutral` | 중립 계열은 점선(색 외 구분) |
| 강조 주석 | `.chart-note` / `svg .note` | 화살표 + 한 줄 |
| 출처 | `.chart-src` | 15px, 기관 · 자료명 · 기준연도 · n |

**필수 부품:** 제목(결론형) · 축 이름+단위 · n과 기간 · 출처·기준일 · 값 직접 라벨 · 강조 주석. 하나라도 빠지면 그 차트는 쓰지 않는다.

## 주장 라벨

결론 등급 + 확인 상태를 숫자·주장 옆에 둔다. 미관 때문에 지우지 않는다.

| 라벨 | 클래스 | 뜻 |
| --- | --- | --- |
| 기술 | `.tag.g-desc` | 관측된 값을 그대로 기술 |
| 추정 | `.tag.g-est` | 표본에서 모집단으로 넓힌 값, 또는 보간 |
| 인과 | `.tag.g-cause` | 원인-결과 주장 — **이 덱에서는 쓰지 않는다** |
| 외부 자료 | `.tag.s-ext` | 공개 통계에서 그대로 인용 |
| 직접 계산 | `.tag.s-calc` | 공개 값으로 이 덱이 계산(예: 인구로 나눈 조율) |
| 미확인 | `.tag.s-unver` | 1차 출처를 확인하지 못함 |

## 용어집

같은 대상은 한 단어로 부른다.

| 쓸 말 | 쓰지 않을 말 | 이유 |
| --- | --- | --- |
| 20대 (19~29세 / 20~29세를 **매번 명시**) | 청년, 젊은 층, MZ | 자료마다 연령 구간이 달라 섞으면 숫자가 어긋난다 |
| 유병률 | 발병률, 환자 비율 | 유병률(존재)과 발생률(새로 생김)은 다른 값 |
| 진료 인원 | 환자 수, 발병자 수 | 진료받은 사람 수일 뿐 아픈 사람 수가 아니다 |
| 조율 | 비율, 발생률 | 연령표준화하지 않은 값임을 드러낸다 |
| 기준연도 | 조사연도, 발표연도 | 데이터가 가리키는 해(발표 연도와 다를 수 있다) |
| 교란 요인 | 변수, 다른 이유 | 수업 용어 |

통계 기호는 처음 한 번 풀어서 쓴다(예: n = 표본 수).

## 문구 모양

- kicker: 명사구. headline: 한 문장, 마침표 없음, 강조 한 곳.
- 본문: 개조식(명사 종결), 마침표.
- 출처: `출처: 기관 · 자료명 · 기준연도 · n`. 숫자 가까이.
- 결론 띠 라벨: 내용 장은 `결론`, 방법 장은 `규칙`, 한계 장은 `한계`.
