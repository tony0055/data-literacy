# 레이아웃

실제 값의 기준은 `../src/tokens.css` + `../src/deck.css`다.

## 캔버스와 여백

| 항목 | 값 |
| --- | --- |
| 캔버스 | 1920 × 1080 |
| 여백 | 좌우 160, 위 112, 아래 64 |
| 내용 폭 | 1600 |

## 그리드

12열 × 104px, 거터 32px. 열 시작 x = 160 + 136n.

- 우선 나눔: 6+6, 4+4+4, 5+7(7+5), 3×4.
- 클래스: `.c3` `.c4` `.c5` `.c6` `.c7` `.c8` `.c9` `.c12`.

## 세로 뼈대

`.slide`는 `grid-template-rows: auto minmax(0, 1fr) auto auto`로 네 영역을 고정한다.

| 영역 | 클래스 | 위치 |
| --- | --- | --- |
| 머리글 | `.head` (`.kicker` → `.headline` → 선택 `.lead`) | 위에서 112 |
| 본문 | `.body` | 머리글에서 64 아래, 남는 높이를 다 쓰고 내용을 세로 가운데 정렬 |
| 결론 띠 | `.sowe` | 본문에서 32, 1px 윗선 |
| 꼬리말 | `.foot` (출처 왼쪽 · 쪽 번호 오른쪽) | 결론에서 24, 아래에서 64 |

네 영역의 자리는 **모든 내용 장에서 같다**. 표지(`.cover`)와 파트 표지(`.part`)만 예외다.

## 간격

8 · 16 · 24 · 32 · 48 · 64 · 96 · 128. 4는 아이콘-글자 반 단계와 라벨 사이에만.

| 쓰임 | 값 |
| --- | --- |
| 카드 안쪽 | 32 |
| 같은 열 블록 사이 | 24 (`.stack`), 좁게 16 (`.stack.tight`) |
| 다른 열 사이 | 32 (거터) |
| 제목 → 본문 | 8 |
| 본문 블록 사이 | 16 |
| 머리글 → 본문 | 64 |

서로 가까운 값(12와 16)을 섞지 않는다.

## 모서리와 그림자

| 토큰 | 값 | 쓰는 곳 |
| --- | --- | --- |
| `--r-card` | 24 | 카드, 질문 블록 |
| `--r-inner` | 16 | 카드 안 블록, 핵심 박스, 수식 |
| `--r-small` | 8 | 표 셀, 작은 요소 |
| `--r-pill` | 999 | 칩, 라벨, 번호 |
| `--sh-1` | 옅은 깊이 | 기본 카드 |
| `--sh-2` | 떠 있는 요소 | 강조 블록 |
| `--sh-3` | 가장 깊음 | 현재 덱에서 쓰지 않음(제품 화면 없음) |

## 밀도 규칙

- 한 장에 블록 최대 4개, 블록 설명은 두 줄이 기본.
- 카드 높이는 내용에 맞춘다. 빈칸을 채우려고 늘리지 않는다.
- 넘치면 글자를 줄이지 말고 장을 나눈다.

## 인쇄

`@page { size: 1920px 1080px; margin: 0 }`. 인쇄에서는 `zoom`을 1로 되돌리고 `box-shadow`·`filter`를 모두 끈다(Chrome PDF가 흐린 그림자를 회색 마스크로 굳히는 문제).
