# 20대는 정말 아파지고 있나 — 발표자료

데이터리터러시의이해 「발표자료 업로드」 과제 제출본 (제출 기간 2026-10-06 ~ 2026-10-23).

| 과제 항목 | 내용 | 링크 |
| --- | --- | --- |
| 발표자료 | 16장 웹 슬라이드 (1920×1080, 약 5분) | **https://tony0055.github.io/data-literacy-youth-health/** |
| 자료조사 | 공개 통계 8종 수집, 출처·연령 구간·확인 경로 기록 | [`research/`](research/) · [`claims.csv`](claims.csv) |
| 데이터분석 | 질문·4칸 명세·결과·대안 설명 검증·한계 | [`report.md`](report.md) · [`verification.md`](verification.md) |

슬라이드 조작: 방향키·Space 이동, Esc 전체 목록, F 전체화면, R 모션 다시 재생. 발표 대본은 [`speaker-notes.md`](speaker-notes.md).

> 처음에는 분석·덱 워크플로우를 시험하려고 `workflow-test/`에서 만들었고, 6주차 이 과제의 제출본이 되면서 `week6/`으로 옮겼다. 수치는 전부 실제 공개 통계이고 합성 데이터는 없다.

"요새 20대 건강이 나빠졌다"는 통념을 공개 통계로 확인하고, 그 결과를 1920×1080 HTML 발표 덱으로 만들었다.

원시자료 접근 없이 **공개 공표값만** 사용했다. 1차 자료에서 직접 전사한 것과 재게시본에서 읽은 2차인용을 구분해 표기했다.

## 산출물

```
report.md            분석 보고서 (질문·4칸 명세·데이터·결과·대안 설명 검증·한계)
claims.csv           주장 18건: 결론 등급 · 확인 상태 · 값 · 연령 구간 · 출처 · 슬라이드
chart-data.json      덱 차트가 읽는 유일한 수치 원본 (11개 데이터셋)
verification.md      손계산·검산 전체 기록
speaker-notes.md     발표 대본 (약 5분) + 예상 질문
research/            하위 에이전트 4대의 수집 원문 (출처·n·미확인 목록)
research/_src/       내려받은 1차 PDF
presentation/        HTML 덱 · 디자인 표준 · 렌더 결과
```

## 실행법

```sh
cd presentation
bun scripts/build.ts            # chart-data.json을 index.html에 주입
bun scripts/render.ts index.html            # renders/index/*.png + 넘침 검사
bun scripts/render.ts design-standard.html  # 표준 확인 화면
bun scripts/render.ts contact.html          # 전 장 컨택트시트
bun scripts/snap-motion.ts 5,8,11           # 모션 단계 스냅샷
bun scripts/render.ts index.html --pdf      # PDF (요청 시에만)
```

Bun 1.4 이상과 Chrome이 필요하다. 덱을 그냥 열어도 된다(`presentation/index.html`). 발표 조작: 방향키·Space 이동, Esc 전체 목록, F 전체화면, R 모션 다시 재생. 장마다 데이터가 순서대로 쌓이는 빌드 모션이 있고, 모션 감소 설정이면 최종 상태를 바로 보여 준다.

## 검증

| 검사 | 결과 |
| --- | --- |
| 전 장 렌더 | 16장, `issues: []` (넘침·가림·작은 글자 없음) |
| 눈으로 확인 | 컨택트시트 + 밀도 높은 장(5·7·8·10·12) 원본 크기 확인 |
| 표 내부 정합성 | 통계청 표 12에서 역산한 남성 인구비중이 2013·2022·2023년 모두 0.52~0.53으로 일치 |
| 성비 재현 | 표의 성비 행 1.4 = 20.9 ÷ 14.8 = 1.41 |
| 파생값 손계산 | %p·배수·증가율 전부 `verification.md`에 기록 |
| 차트-데이터 일치 | 모든 차트는 `chart-data.json`에서만 그린다. `scripts/build.ts`가 주입하고 누락 데이터셋이 있으면 실패한다 |
| 덱 숫자 대조 | `scripts/check-numbers.ts`가 덱 본문의 통계 수치를 원본 파일과 대조 → 미검증 0 |
| 모션 | `scripts/snap-motion.ts`로 시작·중간·최종·모션감소 상태를 찍고 opacity·scaleY·dashoffset을 검사 |

**검산이 바꾼 결정**: 같은 역산을 비만에 적용했더니 2013년 0.525, 2022년 0.479로 어긋났다. 검진 수검자 구성 변화 또는 2013년 전체값(그림 판독)의 부정확 가능성이 있어, **비만의 연도 비교는 성별 값으로만 제시하고 전체값 비교는 덱에서 뺐다.**

## 한계

- 공표값 전사이지 원시자료 재분석이 아니다. 신뢰구간·추세검정을 대부분 확보하지 못해 단순 차이를 유의하다고 쓰지 않았다.
- 조사도구가 바뀐 지점(2014 신체활동 IPAQ→GPAQ, 2014 근력운동 조사방식, 2016 수면 문항, 2019 흡연 문항, 2022 영양 회상기간)에서 시계열을 잇지 않았다.
- 2020~2022년을 가로지르는 비교에는 코로나 영향이 섞여 있다.
- 20대 PHQ-9 우울 유병률 시계열, 제품별 전자담배 사용률, 수면부족 비율, 주관적 건강인지율은 확보하지 못했다. `research/*.md`의 '미확인' 절에 시도한 경로를 남겼다.
- GitHub Pages로 배포했다(2026-10-12): https://tony0055.github.io/data-literacy-youth-health/
