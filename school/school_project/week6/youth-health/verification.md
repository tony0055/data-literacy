# 독립 검산 기록 (2026-10-03)

## A. 통계청 표 12의 '성비(남/여)' 행이 자살률 비로 재현되는가

- 2013년 20~29세: 남 20.9 / 여 14.8 = **1.412** -> 반올림 1.4 · 표 인쇄값 1.4 · 일치
- 2022년 20~29세: 남 24.5 / 여 17.9 = **1.369** -> 반올림 1.4 · 표 인쇄값 1.4 · 일치

## B. 전체 자살률이 성별 자살률과 정합한가

전체율 = 남율 x (남성 인구비중) + 여율 x (1 - 남성 인구비중) 이므로, 남성 인구비중 = (전체 - 여) / (남 - 여).

- 2013년: (18 - 14.8) / (20.9 - 14.8) = **0.525**
- 2022년: (21.4 - 17.9) / (24.5 - 17.9) = **0.53**
- 2023년: (22.2 - 17.6) / (26.4 - 17.6) = **0.523**

세 해의 역산 남성 인구비중이 0.523 ~ 0.53로 일치한다. 한국 20대는 남초라 남성 비중이 0.5를 조금 넘는 것과 맞는다. **표 내부 정합성 확인, 전사 오류 없음.**

## C. 같은 방법을 비만 수치에 적용하면

- 2013년: (21.8 - 10.3) / (32.2 - 10.3) = **0.525**
- 2022년: (31.3 - 18.7) / (45 - 18.7) = **0.479**

자살률은 세 해가 모두 0.52~0.53으로 붙었는데, 비만은 0.525와 0.479로 **어긋난다**. 가능한 설명은 두 가지다.

1. 분모 구성이 바뀜다. 자살률의 분모는 주민등록연앙인구(인구 전체)지만, 비만의 분모는 **국가건강검진 수검자**다. 수검자의 성별 구성은 인구 성비와 다르고, 2013년과 2022년 사이에 검진 대상이 확대되면서 달라졌을 수 있다.
2. 전체 값 중 2013년 21.8%가 그림 판독값이라 정밀도가 낮다(2022년 31.3%와 성별 값은 모두 본문 문장에서 전사했다).

어느 쪽이든 안전한 조치는 같다.
-> **조치: 덱에서 20대 비만의 변화는 성별 값으로만 보여 주고, 전체 값의 연도 비교(21.8 -> 31.3)는 쓰지 않는다.** 2022년 연령대별 비교에는 같은 해 내부 비교라 31.3%를 그대로 쓴다.
