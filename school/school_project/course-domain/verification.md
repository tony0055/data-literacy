원자료 오류·단순화는 수정하지 않고 읽기 원장에 근거와 실행 시 보완 기준을 기록했다. 수치 검증을 차트와 분석 결과의 자기 일치로 대체하지 않도록 명시했다. 역할별 코드 크기는 모두 200줄 미만이며, 새 코드는 스냅샷 관리/요청 계약을 분리하고 기존 unittest 관례를 따른다.

LSP 진단은 `basedpyright-langserver` 미설치로 수행하지 못했다. 새 패키지를 설치하거나 타입 경고를 숨기지 않았다. 원본의 Windows 빌드, 비공개 예비 링크, 미배포 7주 이후 자료와 실제 시험 데이터는 실행 검증 대상에 포함하지 않았다.

이 작업은 지식 보존·실행 하네스 설계다. 새 데이터 분석·학생 발표 덱·공개 배포를 생성한 것은 아니다. 다음 분석/시각화/발표 요청에서는 해당 실제 결과의 수치·렌더·브라우저 검증을 수행해야 한다.
