# 실습·중간고사·팀 프로젝트 대비

기준: [5–16주 계획](../../school_materials/pnu-lectures-2026/f25491512e69/plans/데이터리터러시-5-16주-계획.md) §1·§2·§5 및 실제 2–6주 슬라이드. 계획에 “공식”이라고 적힌 내용도 이 저장소에서 교수계획표·PLATO 공지를 독립 확인한 것은 아니다. 변경된 학교 공지가 우선한다.

## 평가 상태

계획 §2는 출석 10%, 실습과제 30%, 중간고사 20%, 기말 팀 프로젝트·발표 40%를 교수계획표 확인 비중으로 기록한다.

다음은 **확인 필요/설계안**이며 확정 사실로 제출물에 적지 않는다.

- 중간 실기 범위·AI 허용·오프라인·부정행위 기준.
- AI 프롬프트 로그 제출 의무와 양식.
- 팀 3–4명, 발표 8분+질의 4분, 팀 수에 따른 시간 조정.
- 동료평가의 기여도·협업·품질 각 5점과 개인점수 반영 방식.
- 실습 30% 내부 배분안: 8회 주차 과제 24%, 윤리 조사 3%, 진행 점검 3%.
- 실습 환경·설치 권한, 원본 업로드 용량·개인정보 범위.

## 주차별 실습과 산출물

| 주 | 준비·수행 | 보관/제출 구분 |
| --- | --- | --- |
| 1 | 자료 없음; 환경·수업 소개를 추정해 과제로 만들지 않음 | 학교 공지 확인 |
| 2 | 질문·조작적 정의, 출처 실재 확인, 원본 CSV 구조·자료형·결측 | 실습 기록; 상세 과제 양식은 공개 자료에서 별도 확정되지 않음 |
| 3 | 진단만 → 결측 이유 판단 → 삭제/평균 대치 비교 → 로그 → 인코딩 확장 | 로그·전후 통계 보관; 실제 제출 공지 대조 |
| 4 | 단문 요약과 4칸 명세 비교, 평균/중앙값 차이·히스토그램, 집단별 통계 | **수업 내 완료·제출물 없음** (실제 d04 실습 2) |
| 5 | 서로 다른 두 척도 표준화·같은 대상 비교, z/IQR 후보 대조 | 공식 과제: 두 열 평균·SD·n, 상위 5행 z 비교표, 판단 근거 3줄, 히스토그램 2장 (실제 d05 과제) |
| 6 | 같은 데이터의 정직/왜곡 차트, 점검 4문, 결론 비교 | 공식 과제: 차트 2장·기법명·인상 차이·선택 이유·나란한 결론 (실제 d06 명세) |
| 7 | 단문 상관표와 명세 결과 비교, 산점도·이상치·집단별 r·Spearman 확장 | 계획상 공식 과제: 두 변수 상관 분석 |
| 8 | 2–7주 통합 실기·서술 연습 | 중간고사 설계안; 시험 데이터 미배포 |
| 9 | 상관 해석의 동사 검사, 교란 후보 3개, 층화·문장 등급 | 계획상 공식 과제: 상관≠인과 보도·광고 사례 조사 |
| 10 | A/B 구성 6종, 난수 배정·사전 특성, 표본·기간·중단 규칙 | 계획상 공식 과제: 일상 속 A/B 설계서 |
| 11 | 모의 결과 검정, 효과·CI, 효과 0 반복 검정·peeking 비교 | 계획상 공식 과제: 주어진 결과표의 해석과 주장 범위 |
| 12 | 식별/준식별 분류, 소규모 셀 병합·재집계, 이용 조건 | 계획상 공식 과제: 윤리 이슈 사례 조사 |
| 13 | 팀 주제·실물 데이터·1차 진단·9항목 계획 | 계획상 공식 과제: 분석 계획서 |
| 14 | 계획 대비 변경·정제·제외 목록·민감도·메시지·덱 초안 | 계획상 공식 과제: 진행 상황 점검 |
| 15 | 보고서·발표·데이터·실행 기록과 질의 대응 | 팀 최종 제출/평가안 |
| 16 | 잘된 판단 2·보완점 2·재분석 1, 함정 총정리 | 피드백·공개 가능한 포트폴리오 |

실습은 **개념 → 목표·제약·검증 조건·비목표 → 결과 검증**이다. 교육용 단문 요청과 개선 요청을 비교할 때 원본을 보호한 사본에서 수행하고, 실패도 사용 기록에 남긴다. 제출 공지가 없다는 이유로 새 “공식 과제”를 만들어내지 않는다.

공통 채점 대비: 명세 4칸의 구체성, 손계산/기준 변경 검증, 주장 등급·한계, n·제외 행 수·출처. 코드 실행 성공만으로 정확성을 주장하지 않는다.

## 중간고사 대비: 3시간 종합 연습

계획 §1 8주는 개인 실기+서술, AI 사용 내역, 공통 당일 데이터, 결과 파일·정제 로그·서술 답안을 제안한다. 이것을 실제 시험의 확정 규칙으로 전제하지 않는다.

| 영역 | 계획 배점 | 연습에서 확인할 것 |
| --- | --- | --- |
| A 데이터 점검 | 15 | 행·열·단위·식별자·출처; 생성된 데이터 환각 진단 |
| B 정제·로그 | 25 | 결측·중복·인코딩/자료형 오류, 처리 이유·영향 행 |
| C 기술통계 | 20 | 평균·중앙값·SD·n, 분포·이봉·표준화·이상치 근거 |
| D 시각화 2종 | 20 | 질문에 맞는 차트·축·단위·정렬·n |
| E 해석·한계 | 20 | 주장 범위·대안 설명·정제 민감도 |

계획은 함정 #1–#6 중 4개 이상을 데이터에 배치하고 공식 제공·암기 없음·판단 근거 중심을 제안한다. 시험용 데이터는 아직 없다. 연습 요청이 오면 공개/합성 데이터를 별도 생성·확보하고 **연습용**이라고 표시한다. 평가용 정답은 데이터 생성 규칙·독립 손계산으로 만들고 에이전트의 자체 결론을 정답으로 돌려쓰지 않는다.

준비 순서: 원본 진단 → 처리 기준 → 정제 로그 → 수치·분포 → 정직한 차트 2종 → 짧은 해석·한계 → 재실행·제출물 대조. 실제 시험 중에는 허용 범위를 먼저 확인한다.

## 팀 프로젝트: 13–16주

13주 계획은 주제 40분·확보 50분·계획 60분·팀 점검 30분 운영이다. 판단 주체, 한 행의 의미, 4주 범위, 실제 URL·파일·행·변수·라이선스를 먼저 확인한다. 관심 있는 주제라도 실제 데이터가 없으면 통과하지 않는다.

분석 계획 9항목: **질문 / 대상과 단위 / 데이터 / 변수 / 정제 규칙 / 분석 방법과 이유 / 검증 / 한계 / 일정과 역할**. [양식](templates/analysis-plan.md)을 프로젝트로 가져가 채운다. 공개 데이터 후보는 계획 §3의 data.go.kr, KOSIS, 서울·부산 공공데이터, 기상자료개방포털, 문화빅데이터플랫폼이다. 현재 제공 여부는 사용할 때 실제 파일로 확인한다.

14주는 분석 60분·정리 40분·크리틱 50분·발표 초안 30분 운영안이다. 계획 변경, 전체 기간·집단, 제외 목록과 민감도, 결론의 문장 등급을 점검한다. 좋은 결론만 남겨 발표하지 않는다.

| 기말 팀 루브릭 축 | 계획 배점 | 준비 증거 |
| --- | --- | --- |
| 질문 적합성 | 20 | 판단 주체·대상·단위 일치 |
| 데이터·정제 | 20 | 출처·행 수·정제 로그 |
| 분석·검증 | 25 | 방법 선택 근거·손계산·기준 변경 재계산 |
| 해석·한계 | 20 | 주장 등급·교란·대안 설명 |
| 전달 | 15 | 1장 1메시지·축·단위·n·발표 시간 |

필수 질의 준비: (1) 제외 데이터와 이유, (2) 정제 기준을 바꿨을 때 결과, (3) 이 데이터로 주장할 수 없는 것. 각 답변을 실제 로그·표·차트에 연결한다.

발표는 8분+질의 4분이라는 **미확정 수업 계획값**을 준비 기본값으로 쓰고 기록한다. 일반 발표의 4–6분 기본값과 혼동하지 않는다. 최종 학교 공지가 나오면 그것을 따른다. 보고서·발표·실행 기록을 함께 납품하고, 데이터 재배포가 허용되지 않으면 원본 대신 접근·다운로드·전처리 재현 절차를 제공한다.

16주 피드백을 다음 분석에 반영한다. 공개 포트폴리오는 사용 조건과 식별 정보·소규모 셀을 다시 확인한 버전으로 분리하며 요청·허가 없이 공개 배포하지 않는다.
