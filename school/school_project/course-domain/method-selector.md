# 질문 → 방법 → 수식 → 근거 → 차트

분석 방법을 고르는 결정표다. 개념 설명과 원문 근거는 [concepts.md](concepts.md), 실행 순서는 [워크플로우](../../../docs/course-workflow.md)가 소유한다. 상태 표기: **배포**=2–6주 실제 슬라이드, **계획**=5–16주 계획 문서(미배포), **보완**=원문 오류·생략을 실행 기준으로 바로잡은 것([읽기 원장](reading-ledger.md)).

## 1. 질문 유형으로 고르기

| 질문 | 방법 | 수식·기준 | 반드시 함께 보고 | 기본 차트 | 함정 | 상태 |
| --- | --- | --- | --- | --- | --- | --- |
| 이 값들은 대체로 어떤가 | 기술통계 | 평균 = Σx/n, 중앙값, 최빈값, 분산 = Σ(x−x̄)²/(n−ddof), SD = √분산, IQR = Q3−Q1 | n·결측 제외 수·ddof·단위·최소/최대 행, 평균−중앙값 차이 | 히스토그램(구간 폭 민감도), 집단 비교는 상자그림 병행 | #3 평균만 | 배포 4주 + 보완(ddof) |
| 서로 다른 척도의 값을 비교 | 표준화 | z = (x − 평균)/SD, SD=0이면 불가 | 기준 집단·기간·n, 분포 모양 | 두 히스토그램 + z 비교표 | 대칭만으로 정규 백분위 쓰기 | 배포 5주 + 보완 |
| 튀는 값이 있나 | 이상치 **후보** 목록 | \|z\|>3(관례), Q1−1.5·IQR 미만 또는 Q3+1.5·IQR 초과, 도메인 범위 | 양쪽 울타리, 사분위 계산법, 두 기준 교집합·차이 행 ID, 처리 전후 n·평균 | 히스토그램/상자그림 + 후보 표시 | #4 자동 삭제 | 배포 5주 + 보완(양측) |
| 항목별 값·순위 | 집계 비교 | 합계·비율 = 해당 수/분모 | 분모·정렬 기준·제외 행 | 막대(값 축 0), 이름 길면 가로막대 | #5 축·n 누락 | 배포 6주 |
| 시간에 따라 어떻게 | 추세 | 기간별 집계, 증감률 = (b−a)/a | 실제 시간 간격·누락 구간·기간 일치 | 선 | 유리한 기간만 고르기(#12) | 배포 6주, 계획 14주 |
| 전체 중 구성 | 비율 구성 | 부분/전체, 합 = 100% 확인 | 전체 n, 범주 정의 | 누적 막대·트리맵, 파이는 5개 이하·순위용 금지 | 분모 불일치 | 배포 6주 |
| 두 변수가 함께 움직이나 | 상관 | Pearson r = Σ(x−x̄)(y−ȳ)/√(Σ(x−x̄)²Σ(y−ȳ)²); 단조·순위는 Spearman ρ(순위의 Pearson) | r·n·결측 제외·산점도·이상치 전후 r·집단별 r; r²는 단순 선형 맥락에서만 | 산점도(겹침 처리) | #6 산점도 없는 상관표; r=0≠무관(U자) | 계획 7주 |
| 그게 원인인가 | 인과 주장 등급 | 시간 순서 + 관계 + 대안 배제 + 설계 | 교란 후보 3개, 층화 비교, 심슨의 역설·선택 편향 점검 | 층별 막대·산점도 패싯 | #7 인과 문장 자동 생성 | 계획 9주 |
| 바꾸면 효과가 있나 | A/B 실험 설계·해석 | 차이 = 처치 평균 − 대조 평균; 비율 SE = √(p(1−p)/n); 대표본 95% CI ≈ 추정치 ± 1.96·SE | 사전 가설·배정 단위·방식·지표·기간·표본 크기·중단 규칙, 효과 크기·CI·검정 횟수, 탐색/확증 구분 | 점 + 신뢰구간 막대 | #8 배정 없는 A/B, #9 p<0.05 단정 | 계획 10–11주(공식은 표준 통계, 수업 슬라이드 미배포) |
| 예측·분류가 필요한가 | 지도/비지도 학습(선택) | 학습/검증 분리, 시계열은 시간 순서; 정밀도 = TP/(TP+FP), 재현율 = TP/(TP+FN) | 기저 비율, 누출 점검, 전처리는 학습 자료로만 적합 | 혼동행렬, 학습/검증 오차 곡선 | 정확도만 보고 | 배포 6주 보너스 |
| 공개해도 되나 | 개인정보·윤리 점검 | 식별/준식별 분류, k-익명성, 소규모 셀 병합 | 이용 조건·최소 수집·보관 | 집계표 | #10 개인정보 출력 | 계획 12주 |

p값은 "귀무가설과 검정 가정 아래 관측 이상으로 극단적인 결과가 나올 확률"이다. 귀무가설이 참일 확률·효과 크기·재현 확률로 쓰지 않는다. 여러 지표를 검정하거나 중간에 여러 번 확인했으면 그 횟수를 보고한다.

## 2. 결론 문장 등급

| 등급 | 쓸 수 있는 동사 | 필요한 근거 |
| --- | --- | --- |
| 기술 | "~와 함께 움직인다", "~가 더 높다(이 표본에서)" | 정확한 집계·n·분모 |
| 추정 | "~를 설명할 가능성이 있다" | 기술 + 교란 후보 점검·민감도 |
| 인과 | "~가 ~를 변화시킨다" | 무작위 배정 실험 또는 그에 준하는 설계 |

관찰 자료의 높은 r만으로 "효과/때문/증가시킴"이라고 쓰지 않는다. 편의 표본(리뷰·자발 응답)의 결과를 시장 전체·순위로 넓히지 않는다.

## 3. 분석 전 4칸 명세

| 칸 | 채울 것 |
| --- | --- |
| 목표 | 판단 주체, 질문, 한 행의 의미, 대상·기간 |
| 제약 | 원본 보존, 허용한 처리만, 단위·척도, 사용할 방법과 이유 |
| 검증 조건 | 손계산 또는 독립 집계로 대조할 값, 민감도 대안, 렌더 확인 |
| 비목표 | 이번에 주장하지 않을 것, 하지 않을 처리 |
