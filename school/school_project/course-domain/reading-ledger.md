## ZIP 내부 문서

`zip-text/archive-audit.json`은 모든 내부 파일의 경로·바이트·SHA-256·원본 동일 여부다.

- 각 ZIP `index.html`, `READ-ME.txt` 10개: 전체 정독. 과목명이 컴퓨터그래픽스라고 잘못 표시되지만 실제 내부는 데이터리터러시다. 인터넷 연결 필요를 명시한다.
- ZIP 3주 `slides/_shared/demos/d03.js`, 4주 `demos/d04.js`, `slides/w04/index.html`: 바이트가 달라 추가 전체 정독. 의미·실습 요구·동작 설명의 차이는 발견하지 못했다.
