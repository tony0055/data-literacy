# 팀 분석 계획

1. 질문: 누구의 어떤 판단을 돕는가.
2. 대상과 단위: 한 행의 의미·모집단·표본.
3. 데이터: 실제 URL·파일·기관·기간·행 수·이용 조건·해시.
4. 변수: 원본 열 이름·의미·자료형·척도·단위.
5. 정제 규칙: 결측·중복·이상치 기준과 근거·로그 방식.
6. 분석 방법: 기술통계·시각화·상관·비교 중 선택과 이유.
7. 검증 방법: 독립 집계·손계산·기준 변경 재계산.
8. 한계: 빠진 대상·교란 후보·주장할 수 없는 것.
9. 일정과 역할: 주차별 담당·검토자·통합·발표·제출.

실제 파일과 변수 대조가 끝나기 전 계획 완료로 표시하지 않는다. 변경 시 날짜·이유·영향받은 결과를 추가한다.
