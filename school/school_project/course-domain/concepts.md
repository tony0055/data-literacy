## 2주: 질문과 표의 문법

정형은 행·열 표, 반정형은 JSON/XML/로그, 비정형은 리뷰·이미지·음성 등이다. 분석 전에 **질문 → 조작적 정의 → 관측 단위·변수 → 출처와 빠진 대상**을 정한다. 통학시간처럼 일상어인 변수를 출발·도착 기준과 분 단위로 정의하고, 그 정의가 포함·제외하는 상황을 기록한다.

- 한 행은 관측 하나, 한 열은 변수 하나, 한 셀은 값 하나. 학생·수업·학과를 혼동하면 분모가 바뀐다.
- 명목: 같음/다름·빈도·최빈값. 숫자 코드를 평균 내도 범주 평균은 의미가 없다.
- 순서: 크기 순서·중앙값. 만족도 1–5점의 간격 동일성을 당연시하지 않고 분포를 함께 보고한다.
- 구간: 간격은 일정하나 절대 영점이 없다. 섭씨 20도가 10도의 두 배 온도라는 해석은 하지 않는다.
- 비율: 절대 영점이 있는 시간·금액 등. 단위와 비교 대상을 맞추면 비율 비교 가능.
- tidy: 연도별 열을 길게 펼쳐 `학과, 연도, 인원`처럼 구성. 표 머리글·합계행을 관측값과 섞지 않는다.
- 설문은 질문·척도·응답자 선택, 공공데이터는 변수 적합성·출처, 웹 자료는 이용 조건·표본 편향을 확인한다.
- 자발적 응답·생존자 편향은 표본을 늘려도 사라지지 않는다. “이 데이터에서 빠진 사람은 누구인가?”에 먼저 답한다.

함정 #1: 없는 데이터·출처를 AI가 생성. 실제 링크 접속, 파일 확보, 기관·연도·대상·행·열을 확인한다. “AI가 알려줌”은 출처가 아니다.

근거: d02 `표의 문법`, `평균을 낼 수 있는 값, 없는 값`, `수집 설계`, `누구에게 물었는가`, `생존자 편향`; 도해 `d02-collection-design`, `d02-scales`, `d02-tidy`.

## 3주: 진단과 처리를 분리

진단만 할 때 원본 해시·행 수를 고정하고 자료형, 결측의 실제 표기, 고유값, 완전 중복을 조사한다. `-`, `미상`, 빈칸을 같은 결측으로 볼지 변수별로 결정한다. 숫자의 쉼표·%·단위, 날짜 형식, 앞자리 0이 필요한 식별자도 확인한다. 인코딩 오류는 원본 손상과 읽기 설정 불일치를 구분한다.

결측의 이유는 무작위, 다른 관측 변수와 관련, 결측값 자체와 관련인 경우로 나누어 판단한다. 이유는 단순 결측 비율만으로 확정할 수 없다. 삭제·대치·유지의 선택과 한계를 기록한다. 평균 대치는 관측값 기준 평균을 유지할 수 있지만 흩어짐을 축소하므로 기본값으로 쓰지 않는다.

중복은 관측 단위·키에 따라 판단한다. 같은 사람의 두 학기 기록은 중복 삭제 대상이 아닐 수 있다. 통학 480분처럼 큰 값도 원본·단위·대상 확인 전에 제거하지 않는다.

정제 로그: **무엇을 / 왜 / 어떻게 / 영향받은 행**. 유지 결정과 규칙 변경도 기록한다. 원본·정제본을 나누고 단계별 전후 행 수와 결과를 대조한다. 결과가 마음에 들지 않는다고 사후 규칙을 바꾸지 않는다.

함정 #2: 평균 대치·중복/이상치 삭제·자료형 변환을 조용히 수행. 먼저 진단 보고, 결정한 처리만 실행, 로그·전후 행 수를 검증한다.

근거: d03 `숫자처럼 보이는 문자`, `결측치가 생기는 이유`, `같은 데이터, 다른 결론`, `정제 로그`; 도해 `d03-missing-why`, `d03-mean-imputation`, `d03-cleaning-log`.

## 4주: 숫자 요약과 분포

- 평균 = 합계/n, 중앙값 = 정렬한 가운데 값, 최빈값 = 가장 빈번한 값.
- 분산은 편차 제곱의 평균, 표준편차는 그 제곱근. 분산의 단위는 원 단위의 제곱, 표준편차는 원 단위다.
- 강의의 5명 예시 `60,70,75,80,90`: 평균 75, 제곱편차 합 500, n으로 나눈 분산 100, 표준편차 10. **수업 예시는 모집단식**이다.
- 실행 보완: 표본 표준편차는 n−1을 분모로 쓰므로 같은 예시에서 값이 달라진다. 코드의 `ddof`, 모집단/표본 선택, 결측 제외 기준을 보고해야 한다.
- 연봉 수준·대기시간처럼 치우침과 극단값이 있으면 중앙값이 일반적인 수준을 표현하기 쉽다. 예산 총액은 평균×인원이 관련된다.
- 평균·중앙값·둘의 차이·표준편차·n·최소/최대와 해당 행을 함께 보고한다. 분포를 그리지 않은 평균 해석은 보류한다.
- 대칭·좌/우 치우침·이봉을 구분한다. 이봉이면 실제 집단 구분 변수를 검토한다. 요약 통계가 같아도 모양이 다른 앤스컴 사례를 기억한다.

함정 #3: 평균만 출력. 중앙값·표준편차·n과 히스토그램을 요구하고 “평균으로 요약 가능한가, 왜인가”를 답한다.

근거: d04 `흩어진 정도의 측정`, `분포의 모양 네 가지`, `앤스컴 4중주`, `이번 주 명세`; `d04-variance-steps` 도해. **4주 실습은 히스토그램 구간 20개 이상·기본 색·제출물 없음**으로 명시돼 있다. 이 실습 전용 조건을 모든 분석에 강제하지 않는다.

## 5주: 표준화와 이상치 후보

`z = (x − 평균) / 표준편차`. 0은 평균, 부호는 평균 위/아래, 크기는 표준편차 몇 칸 떨어졌는지다. 국어 80점(평균 85, SD 5)은 −1, 수학 80점(평균 60, SD 10)은 +2다. 전체 기준과 집단 기준은 다른 질문이므로 대상·기간·n을 명시한다.

정규분포에 가까운 경우의 경험 규칙은 ±1σ 약 68%, ±2σ 약 95%, ±3σ 약 99.7%. **단순 대칭만으로 정규분포나 해당 비율을 보장하지 않는다.** 표준화는 분포 모양을 정규분포로 바꾸지 않는다. 치우침·이봉에서 z를 확률·백분위로 바로 바꾸지 않는다.

| 기준 | 식 | 판단 |
| --- | --- | --- |
| z | 일반적으로 \|z\| > 3 후보 | 극단값이 평균·SD를 움직여 미탐지 가능 |
| IQR | Q1−1.5×IQR 미만 또는 Q3+1.5×IQR 초과, IQR=Q3−Q1 | 치우침에 상대적으로 강하나 이봉 과소 탐지 가능 |
| 도메인 | 단위·입력 오류·현실 범위의 근거 | 숫자 임계값은 출처와 대상 정의가 필요 |

후보는 오류·실제 극단값·대상 외 여부로 나누어 유지/분리 보고/제외한다. z와 IQR의 교집합·차이 행을 원본 ID로 제시한다. 처리 시 기준·전후 n·제외 전후 평균을 남긴다.

실행 보완: SD=0이면 z를 정의할 수 없다. 관측값 부족, 상수 열, 사분위수 계산 방법을 확인하고 불가능한 계산을 0으로 채워 성공 처리하지 않는다.

함정 #4: 히스토그램 없이 ±2σ/±3σ 자동 삭제. 두 기준으로 **목록만** 만들고 분포·원본을 보고 판단한다.

근거: d05 `경험 규칙의 성립 조건`, `기준 범위의 선택`, `처리 세 가지와 보고 형식`, `이번 주 과제`; 계획 §1 5주.

## 6주: 질문에 맞는 정직한 그림

| 질문 | 기본 차트 | 검증 |
| --- | --- | --- |
| 항목의 값·순위 | 막대, 긴 이름/많은 항목은 가로막대 | 막대 값 축 0 시작·정렬 이유 |
| 시간 추세 | 선 | 실제 시간 간격·누락 구간·기간 일치 |
| 분포 | 히스토그램, 집단 비교에 상자그림 병행 | 구간 폭 변경·봉우리; 상자그림만으로 이봉 판별 불가 |
| 두 변수 관계 | 산점도 | 군집·이상치·겹침; 상관표만으로 끝내지 않음 |
| 구성 비율 | 누적 막대·트리맵, 제한적으로 파이 | 전체·분모 일치; 파이 5개 이하, 순위용 금지 |
| 두 범주의 교차 패턴 | 히트맵 | 색 범위·빈 셀·정확한 수치 별도 제공 |

점검 4문: **축 시작값 / 단위 / 정렬 / n**. 제목·출처·기준일·제외 행 수도 필요하다. 막대 0 시작 조건을 산점도·모든 선 그래프의 축에 기계적으로 적용하지 않는다. 비영점 축이 필요한 경우 이유·범위를 공개한다.

100→104는 4% 증가다. 축을 99에서 시작하면 막대 길이는 1→5로 보이지만 값이 5배라는 뜻은 아니다. 이중 축 교차점은 축 범위의 산물이다. 값이 2배인 원은 반지름 √2배로 면적을 맞춰야 한다. 3D 원근으로 값을 꾸미지 않는다.

구간 폭을 바꾸면 단봉/이봉/잡음 인상이 달라진다. 강조색 1개, 나머지 중립색, 범주에 순서형 컬러맵 남용 금지, 색 외 모양·위치로 구분한다.

함정 #5: 기본값 차트의 축·단위·n·정렬 누락. 명세에 넣고 렌더된 결과를 확인한다. 과제용 왜곡 차트는 원본 값 동일성을 확인하고 파일명·그림·설명에 왜곡 기법을 명시하며 최종 의사결정 차트와 분리한다.

근거: d06 `차트별 강점과 약점`, `차트 점검 4문`, `정직한 표현의 조건`, `이번 주 명세`; 계획 §1 6주.

### 6주 보너스: 머신러닝은 선택

지도학습은 정답 있는 회귀·분류, 비지도학습은 군집 등이다. 군집의 단위·척도와 개수 선택에 따른 변화를 확인하고 이름은 분석자가 해석한다. 학습/검증을 분리하고 시계열은 시간 순서로 나눈다. 불균형 분류에서 정확도만 보고하지 않고 정밀도·재현율과 기저 비율을 함께 본다.

강의의 학습 70–80%/검증 20–30%는 예시다. 실행 보완: 전처리·표준화·특징 선택은 학습 자료로 적합하고 검증 정답은 선택에 사용하지 않는다. 검증 오차를 줄이려고 반복 선택한 자료는 독립 최종 평가 자료가 아니다.

기술통계와 시각화만으로 완결된 분석도 가능하다. 근거: d06 `학습 데이터와 검증 데이터`, `과적합`, `정확도 95%의 함정`, `이 수업에서의 위치`.

상관 강도 구간은 분야 의존적이다. r=0도 U자 관계가 없다는 뜻은 아니며 점 하나·표본 범위·집단 혼합을 확인한다. r²의 설명 비율 해석은 해당 단순 선형 관계의 맥락에서만 쓴다. 생태학적 오류처럼 지역 평균의 관계를 개인에게 옮기지 않는다.

결론 등급: 기술 “함께 움직임” → 추정 “설명할 가능성” → 인과 “변화시킴”. 인과에는 시간 순서·관계·대안 배제와 적합한 설계가 필요하다. 관찰 자료의 높은 r만으로 “효과/때문/증가시킴”이라고 쓰지 않는다.

p값은 귀무가설과 검정 가정 아래 관측 통계량 이상으로 극단적인 결과의 확률이다. 귀무가설이 참일 확률·효과 크기·재현 확률이 아니다. 20개 지표 검정이나 반복 peeking의 우연 유의를 보고에서 숨기지 않는다. 실질적 의미와 통계적 유의성을 분리한다.

무작위 배정은 기대상 균형을 만들지만 유한 표본에서 완전 균형을 보장하지 않는다. 표본 수는 효과·변동·유의수준·검정력·설계에 따라 달라진다. 계획의 “효과 2%는 10%보다 약 25배 표본”은 다른 조건이 같은 경우의 감각 예시이지 모든 A/B의 고정 계산식이 아니다.

수업 계획은 개인 식별 자료 수집 금지, 공개·합성 데이터 사용을 요구한다. k익명성만으로 재식별 위험이 모두 해결되는 것은 아니다. 모의 데이터·시뮬레이션은 “교육용 합성”과 생성 규칙·시드를 명시하고 실제 집단의 증거로 보고하지 않는다.
